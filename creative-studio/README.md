# Mise

A focused, local-first screenplay editor. The current milestone is to make writing fast and dependable before adding creative AI features.

## Run it

```bash
npm install
npm run dev
```

## Current editor

- Industry-style scene, action, character, dialogue, parenthetical, and transition elements
- Keyboard-first formatting and automatic element flow
- Scene navigation and drag-to-reorder
- Local autosave, undo/redo, snapshots, find/replace
- Fountain import/export and print/PDF output
